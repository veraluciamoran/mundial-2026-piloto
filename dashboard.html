Diseño de investigación

El proyecto plantea un estudio observacional retrospectivo basado en la fase de grupos del Mundial 2026.

La pregunta central es:

¿En qué medida la carga de desplazamiento entre sedes se asocia con el desempeño deportivo de las selecciones?

El Grupo A funciona únicamente como piloto para validar la construcción de datos, las variables de movilidad y la arquitectura del análisis.

Variables del proyecto

Exposición principal: movilidad
  • distancia desde la sede anterior;
  • distancia acumulada hasta cada partido;
  • cantidad de cambios de sede.
Resultados deportivos
  • puntos obtenidos;
  • diferencia de goles;
  • victoria, empate o derrota;
  • posición del grupo;
  • clasificación a la siguiente fase.
Variables de contexto previstas
  • días de descanso;
  • fortaleza previa de la selección;
  • fortaleza del rival;
  • cambio de huso horario;
  • temperatura;
  • altitud;
  • condición de anfitrión.

Plan de análisis

1. Descripción de la movilidad

Caracterizar recorridos, distancias, descanso y diferencias entre grupos.

2. Análisis exploratorio

Examinar cómo distintas medidas de movilidad se relacionan con indicadores de desempeño.

3. Modelamiento

Evaluar la asociación entre carga de viaje y desempeño incorporando variables de control, entre ellas fortaleza propia, fortaleza del rival y descanso.

La especificación estadística definitiva se seleccionará después de examinar la estructura y distribución de la base completa.

4. Sensibilidad

Comprobar si las conclusiones cambian al utilizar distintas definiciones de movilidad y desempeño.

Unidades de análisis

El proyecto utilizará dos estructuras complementarias.

Selección

Una observación por equipo para estudiar el desempeño agregado durante toda la fase de grupos.

Selección–partido

Una observación por cada selección en cada encuentro.

Esta segunda estructura permite relacionar la movilidad inmediatamente previa al partido con el resultado obtenido en ese encuentro.

Medición de la movilidad

Los partidos de cada selección se ordenan cronológicamente.

Para el piloto, la distancia entre dos sedes consecutivas se estima mediante la fórmula de Haversine, utilizando las coordenadas geográficas de los estadios.

Así se obtiene una medida comparable de la carga de desplazamiento generada por el calendario.

Esta medida no representa necesariamente:

  • la ruta aérea exacta;
  • el hotel del equipo;
  • el centro de entrenamiento;
  • los traslados terrestres adicionales.

Por ello se interpreta como distancia entre sedes y no como distancia logística total.

Trazabilidad

La base original conserva una tabla de fuentes para registrar la procedencia de las variables utilizadas.

En la versión completa, cada fuente deberá documentar:

  • organismo o proveedor;
  • variable utilizada;
  • fecha de consulta;
  • enlace;
  • transformaciones aplicadas.

La trazabilidad detallada permanecerá en el repositorio y en las bases del proyecto; el dashboard mostrará únicamente la información necesaria para interpretar el análisis.
