# Mundial 2026: distancias y desempeño

Piloto técnico del área de Data Analytics de IISE UTEC.

## Dashboard interactivo

El piloto puede explorarse en:

[Ver dashboard interactivo](https://veraluciamoran.shinyapps.io/dashboard/#inicio)

## Pregunta de investigación

¿Existe una asociación entre la distancia recorrida entre las sedes consecutivas de los partidos y el desempeño de las selecciones en el Mundial 2026?

## Alcance del piloto

El piloto utiliza los datos reales del Grupo A:

- México
- Sudáfrica
- República de Corea
- Chequia

El objetivo es validar:

1.  la estructura de las bases;
2.  el procesamiento reproducible en R;
3.  el cálculo de distancias;
4.  la construcción de indicadores;
5.  la visualización geográfica;
6.  el dashboard interactivo con Quarto y Shiny.

## Limitación principal

Las distancias representan la distancia geodésica entre las sedes de partidos consecutivos. No incluyen hoteles, centros de entrenamiento, traslado inicial ni rutas aéreas reales.

Con solo cuatro selecciones no es posible obtener conclusiones estadísticas generales sobre el torneo.
